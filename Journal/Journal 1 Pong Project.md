9/21/2026

	Today was the first day of working on revamping the basic Pong game. Deciding how to revamp Pong was a very enriching experience, as it forced me to question how certain modifications can change the game and if they would ultimately change the main objective of the game. After pondering for some time, I decided to alter the following: make the ball's speed increase every time it hits a paddle (both player and CPU), make an additional ball spawn after a certain amount of paddle hits, and have the game end once all balls exit the field. In coming up with these changes, it shifts the game goal from "score X amount of points to win" to "maintain ball momentum with the CPU to prevent a mutual loss", which brings about a cooperative element to an otherwise single-player game experience. 

	Applying said wanted modifications brought about some difficulty for me, as I am not familiar with the C# coding language enough to know how to alter the code to fit the new needs I desire. As a result, I consulted various YouTube videos and various Unity and coding question threads to assist me in applying said modifications. 
	
	The first and easiest change I implemented was removing the scoreboard, as there was no need for it since there is no score to keep track of. To do that I just deselected the scoreboard in the hierarchy to remove it from the game scene. Following that, when it came to increasing the ball's speed, I added the float value speedIncrease and set it to 5.0f. Following that, I addded the private void function of OnCollisionEnter2D(Collision2D collision) allowing me to check if the ball interacted with a paddle and if it did to increase its speed by 5 by using speed += speedIncrease; and AddStartingForce();. When it came to spawning another ball, I had to follow a similar approach of adding two new values of private int paddleHits = 0; and public int hitsPerSpawn = 4;. These would later be used in the two new void functions, public void RegisterPaddleHit(), which checked and recorded every time a ball interacted with a paddle, and private void SpawnNewBall(), which would spawn a new ball after the spawned balls interacted with the paddle four times. 

	All in all, this process was quite challenging for me as I am not familiar with the terms and language yet for C#, making it difficult to think about how to approach tackling the changes let alone doing them. While the alterations I wanted are implemented, I will go back into Unity to refine the code and see if I can improve it all while implementing some cosmetic changes as well for a new visual look.

This adds a layer of cooperativeness and expands the boundaries of play to more than just one person, making it more interactive. Furthermore, I fine tuned the ball speed so that when new balls spawn the speed of them increases making the game increasingly more challenging. The last major change I implemented was a game over screen once all of the balls exit the field. 
	
	The process of implementing the changes today were a lot smoother than yesterday, as the changes were mostly cosmetic.
